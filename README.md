# ClassicModels SQL Analysis Project

## 📌 Project Overview

It contains customer, employee, office, product, order, order detail, and payment data.

The project is designed to practice SQL concepts.

## 🛠️ SQL Concepts Used

- SELECT and WHERE
- AND, OR, IN, LIKE
- ORDER BY and LIMIT
- Aggregate Functions: `COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`
- GROUP BY and HAVING
- INNER JOIN
- CONCAT()
- Date and Year-based filtering
- INSERT, UPDATE and DELETE
- Foreign Keys


## 🎯 Objective

The main objective of this project is to strengthen **MySQL querying, data analysis, aggregation, joins, and business problem-solving skills** using a realistic relational database.

## 👨‍💻 Skills Demonstrated

**MySQL | SQL | Data Analysis | Relational Databases | Business Analytics**
